## 2. Шрифты

- Карусели/обложки: system sans-serif, крупный кегль, читаемость с телефона первее красоты
- Подписи/метки слоев: моноширинный акцент (blueprint-школа `8-cover.jpg`)
- Заголовок обложки: болд, белый, одна строка смысла

## 3. Форматы и размеры

| Формат | Размер | Назначение |
|---|---|---|
| Cover | 1200×644 (допустимо ≈16:9, напр. 1344×768) | Обложка Pulse = превью фид-поста (клик открывает статью) |
| Inline | 960×425 | Скриншоты внутри статьи |
| Carousel | PDF 1080×1350 (4:5 портрет), без эмодзи на слайдах, крупный шрифт | Магнит охвата в ленте |
| Feed image | отдельного нет для Pulse (cover подхватывается автоматом) | — |

В `alt text` — ключевую метрику.

## 4. Обязательные элементы

- **Big number first** — сильнейшее число вверху/первым (хук превью ~150 chars для текста, верхний блок для визуала)
- **Bottom-line** — каждый визуал несет вердикт одной строкой (желтым), читается без статьи
- **Баттл-фрейм** — `$X vs $Y`, до/после, `X won` (топ-3 хитов — все сравнения)
- **Футер:** `© Victor Ematin · AI Quality Engineering Lead · OpenCode Go` — последняя страница карусели обязательно (PDF скачивается); для баттл-таблиц + строка бюджета (`OpenRouter budget / Spent`)
- **Без хештегов/логотипов на картинках**, без мелкого нечитаемого текста, без вотермарок

## 5. Три школы (все валидны, не смешивать в одном ассете)

1. **HTML→PNG баттлы** — таблицы сравнения, цветовое кодирование win/loss, футер с бюджетом
2. **Blueprint** — чертежная сетка, пастельные блоки слоев, моноширинные подписи
3. **GitHub Dark карусель** — `#0d1117`, огромные числа, no emoji, bottom-line на слайде

## 6. Пайплайн (без VPN-зависимостей)

1. **HTML→PNG локально** (Playwright скриншот) — таблицы, схемы, карусельные слайды. Layout контролируем мы, VPN не нужен
2. **Image-gen для обложек** (`google/gemini-2.5-flash-image` через OpenRouter, ~$0.05/шт) — потом ручная проверка спеллинга: модели коверкают слова (кейс 22: `TIMOUT`, `OWNORSHIP`, дубли). Промпт без упоминаний прошлых ошибок
3. **NotebookLM / Gemini scenario** — опционально, когда доступно (сценарий → пользователь генерирует сам)

## 8. Ротация форматов (заморожена 2026-09-05)

Моноформат = смерть охвата: вирусные недели — всегда связка форматов, одиночные article-only выходы — 34–118 imp. Не повторять один формат 2 раза подряд в ленте одного читателя (то же правило, что для хуков карусель vs статья).

| Слот | Формат | Роль | Доказательство |
|---|---|---|---|
| 1 | Note / текст+картинка | проблема, завязка | 22-note |
| 2 | Carousel PDF 1080×1350 | визуальный фреймворк, dwell time | 13-карусель 23K |
| 3 | Pulse + фид-пост | глубина, saves, credibility | 82K-пост → 451 views, 56 saves |
| 4 | Discussion / checklist | вовлечение, комменты | 10-sec test |
| 5 | Battle-пост `$X vs $Y` | охватный spike | 82K, 20K funnel |

Ритм серии: 2 якорных поста/нед (см. publication-plan). Неиспользованный резерв: polls, короткие video/demo-agent-run, newsletter-дайджест.
