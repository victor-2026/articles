# Платные англоязычные площадки для ИТ-статей (гонорар)

Справочник каналов для англоязычных версий материалов серии (mutation/verdict-тематика). Источник подборки: `ai-qa-wiki/raw/Где писать об ИТ.html` (актуальность источника: 30.09.2026). Проверка W5: все 7 реалистичны, красных флагов нет.

Связанные страницы: [Правила написания](article-writing-rules.md) · [Публикация и мониторинг](pre-publish-and-monitoring.md)

---

## 1. IEEE Spectrum

- Профиль: инженерия, вычисления, ИИ, техноизменения. Нужны журналистские истории с фактами, интервью, независимыми источниками.
- Гонорар: новости — от $500; развернутые материалы — от $1.25 за слово.
- Контакт: знакомство с редактором (о себе + примеры + история). spectrum.ieee.org
- Fit для серии: высокий — mutation/verdict-тематика ложится лучше всего (W5).

## 2. Smashing Magazine

- Профиль: веб-разработка, UX, доступность, дизайн-системы, практические кейсы.
- Гонорар: предусмотрен, публичной ставки нет.
- Контакт: план 200–300 слов через форму (тема, аудитория, польза, экспертиза). smashingmagazine.com
- Fit для серии: средний — только UI/UX-находки кампаний.

## 3. MSSQLTips

- Профиль: SQL Server, интеграция данных, Azure Data Factory, Power BI, Microsoft Fabric.
- Гонорар: оплата + бонусы, сумму уточнять у редакции.
- Контакт: анкета (LinkedIn, пример текста, идеи). Материалы эксклюзивные, AI-генерация запрещена.
- Fit для серии: низкий — вне домена.

## 4. SigNoz Technical Writer Program

- Профиль: backend, DevOps, мониторинг, OpenTelemetry. Подробные руководства с кодом и схемами.
- Гонорар: по экспертизе, согласуется до старта.
- Контакт: тема + примеры публикаций через форму. signoz.io
- Fit для серии: средний — CI/инфраструктурные углы (варианты, свопы, пайплайны).

## 5. Corellium Contributor Program

- Профиль: мобайл-безопасность, пентестинг, threat research. Статьи, white papers, вебинары.
- Гонорар: оплачиваемая, ставка не опубликована.
- Контакт: тема + план + пример текста. Ранее опубликованное и AI-generated не принимают.
- Fit для серии: низкий — вне домена.

## 6. PHPTRAVELS Content Program

- Профиль: travel tech (API поставщиков, платежи, бронирование, архитектура, DevOps).
- Гонорар: $50–200 за принятый материал.
- Контакт: краткое описание идеи; писательский опыт необязателен. phptravels.com
- Fit для серии: низкий — вне домена.

## 7. Draft.dev

- Профиль: агентство техконтента для ИТ-компаний; регулярные заказы на статьи и руководства.
- Гонорар: оплачивается, публичной ставки нет.
- Контакт: анкета на сайте; берут разработчиков разного опыта. draft.dev
- Fit для серии: высокий — регулярный канал под AI-QA тематику (W5).

## Порядок действий (из источника)

1. Подготовить короткое предложение темы + план + 2–3 примера текстов.
2. До написания согласовать гонорар, способ оплаты и права на материал.

## Статус использования

- Не использовано (занесено 03.10.2026). Первый кандидат при готовности англо-версии: IEEE Spectrum или Draft.dev.
