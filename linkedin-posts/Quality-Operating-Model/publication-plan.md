## Гипотеза H4: daily-ритм через связки Дайджест→Новость→Статья (не активна)

Идея: 2 якорных поста/нед + 2-3 легких news-bridge в междудневье (новость из daily-дайджеста + 2 строки + ссылка на свою статью по теме). Материал уже есть: дайджест генерируется ежедневно, блок «Нам полезно» — готовые подводки.
Пилот (когда осилим): 2 недели, стоп-правило — медиана imp якорей < 300 или рост отписок. Статус: отложена, сначала «консервы».

## Консервы (банк готовых постов против провалов)

Правило: держать ≥3 опубликованных без подготовки поста (текст + картинка + хештеги + author line). Форматы-кандидаты — вечнозеленые, не привязаны к датам:
- [ ] Checklist-одиночка (10-sec test карточкой, без статьи)
- [ ] Battle-реприза (старые числа новым хуком, напр. KISS $0.19 vs Autonoma $3.62)
- [ ] Digest-bridge (новость недели + ссылка на свою статью)
- [ ] Pilot-апдейт (QAEverest B1 100%, testRigor 3+3 — уже обещан write-up)
